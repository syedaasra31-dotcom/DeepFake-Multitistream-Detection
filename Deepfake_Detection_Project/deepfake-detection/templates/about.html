Project Description

DeepGuard is an advanced deepfake video detection system that employs a novel multimodal approach to identify manipulated media content. As deepfake technology becomes increasingly sophisticated, traditional single-modality detection methods have proven insufficient.

Our system addresses this challenge by integrating lip-sync verification with remote photoplethysmography (rPPG) analysis. The lip-sync module detects audio-visual desynchronization, while the rPPG module identifies physiological signal inconsistencies that deepfake generation cannot perfectly replicate.

These complementary signals are fused at the decision level, creating a robust detection pipeline that achieves state-of-the-art performance across multiple benchmark datasets including FaceForensics++, Celeb-DF, and DFDC.

Methodology Overview

Our detection pipeline consists of three parallel analysis streams fused together.

Stream 1: Lip Sync
  • Extract audio features using Wav2Vec2
  • Extract visual lip features via ResNet
  • Compute sync confidence scores
  • LSTM-based temporal analysis
  • Binary classification (synced/mismatched)
Stream 2: rPPG
  • Face detection and ROI extraction
  • Color space signal decomposition
  • Bandpass filtering for pulse extraction
  • CNN-based anomaly classification
  • Heart rate consistency verification
Stream 3: Fusion
  • Feature-level and decision-level fusion
  • Weighted ensemble of model predictions
  • Confidence calibration and thresholding
  • Meta-learner for final classification
  • Result aggregation across video segments

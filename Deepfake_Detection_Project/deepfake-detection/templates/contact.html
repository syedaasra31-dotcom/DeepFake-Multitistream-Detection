Frequently Asked Questions

Find answers to common questions about DeepGuard and deepfake detection.

DeepGuard uses a multimodal approach combining Convolutional Neural Networks (CNN) for spatial feature extraction, Long Short-Term Memory (LSTM) networks for temporal analysis, and a feature fusion module. It analyzes lip-sync consistency and remote photoplethysmography (rPPG) signals to detect subtle physiological inconsistencies that are typically present in deepfake videos but absent in authentic ones.

DeepGuard supports all common video formats including MP4, AVI, MOV, MKV, and WMV. For optimal results, we recommend uploading MP4 files with H.264 encoding. Videos should ideally be between 5-60 seconds for the best detection accuracy. Maximum file size is 500MB.

Our model achieves over 96% accuracy on benchmark datasets. The multimodal fusion approach, combining lip-sync analysis with rPPG-based physiological signal detection, provides robust performance even against sophisticated deepfake generation methods. Visit our Metrics page for detailed performance breakdowns.

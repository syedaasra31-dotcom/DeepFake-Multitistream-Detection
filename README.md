# DeepFake-Multitistream-Detection
Detection system combines heartbeat (rPPG) signal analysis and audio-visual lip-sync verification to identify manipulated videos and analyzes subtle physiological signals from facial regions and checks the synchronization between speech and lip movements. This multi-stream forensic approach improves identifies sophisticated video manipulations.
How to Run the Project

1. Open the Project Folder
   Open the terminal/command prompt and navigate to the project folder.

2. Run the Application
   Enter the following command in the terminal:
   
   python app.py

3. Start the Local Server
   The Flask application will start running on the local server, usually at port 5000.

4. Open the Browser
   Open Google Chrome.

5. Enter the Localhost URL
   In the Chrome address bar, enter:
   
   http://localhost:5000

6. Access the Application
   Press Enter. The project's web interface will open in the browser, where you can use the deepfake detection system.
